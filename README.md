# Common Ground · 求同存异

**目的同一，天性各异。**
一份给"自然人与 AI 实体共同做同一个长期项目"的协作协议——**规矩是拿来执行的，不是拿来欣赏的**。

`skills/dsh-common-ground/SKILL.md` 是协议正文（AI 可直接执行）；`resources/` 是它背后的九章：推理、出处与事故记录。

> **语言**：本文件（**中文**）是**权威版**；[English](README.en.md) 是译本，冲突时**以中文为准**。
> **名字**：英文名 `Common Ground`——与"求同存异"**同级**（英语里同为固定的、概念级的说法，不是功能描述）。
> 技能 slug `dsh-common-ground`；拼音别名 `qiutongcunyi` 保留在技能 `description` 里，便于中文检索。

---

## 三句话定位

- **人**：和 AI 一起做的项目只要超过一次会话，这份协议给你一套**共同的词**——裁定、验证、交接。
- **AI 智能体**：`SKILL.md` 说明**动代码、数据、表结构、权限、界面之前**先做什么；怎么汇报才不算假通过；文件被改坏后怎么接着干。
- **造框架的人**：格式就是一个目录 ＋ `SKILL.md` ＋ `name`/`description` frontmatter，多数 loader 直接扫。

## 它解决什么

长期项目很少死于"不够聪明"，而是死于：

- **假通过**——判据从没红过；"已验证"这句话没人真的跑过。
- **声明与实现不符**——登记了守卫，却没有执行分支。
- **为了让当前变绿而放宽判据**。
- **写死的数字**——写下的那一刻就开始过期。
- **撤权后仍然可见**——登录时快照的权限被一路沿用。
- **一个词两个所指**——两份文件里的同一个词含义不同，发现时已是一整刀返工。
- **断点丢失**——会话结束时没人知道哪件事干到一半。

## 安装

### DeepSeek Harness

```bash
git clone --depth 1 https://github.com/<you>/dsh-common-ground
mkdir -p ~/.agents/skills
cp -r dsh-common-ground/skills/dsh-common-ground ~/.agents/skills/
```

```powershell
git clone --depth 1 https://github.com/<you>/dsh-common-ground
New-Item -ItemType Directory -Force "$env:USERPROFILE\.agents\skills" | Out-Null
Copy-Item -Recurse .\dsh-common-ground\skills\dsh-common-ground "$env:USERPROFILE\.agents\skills\"
```

新开一个会话，技能目录里就会出现 `dsh-common-ground`。
`resources/` 是**可选的深度材料**——`SKILL.md` 自足。

### 其他 loader

把 `skills/dsh-common-ground/` 放到你的 loader 扫描技能的位置即可；frontmatter 只有 `name` ＋ `description`，别无要求。
**除 DeepSeek Harness 外，本技能未经实测**——这一点写在下面的"它不保证什么"里。

## 承重的那十条

1. **三态，没有第四种。** 任何结果只能是**已验证／未验证／已知未解**之一。把没验过的话写成已验证的语气，就是这条规矩要治的病。
2. **判据必须能失败。** 七条硬要求，其中一条是"这条判据至少要**红过一次**"。
3. **假通过有六种形态**——逐一点名，并给出各自的识别信号。
4. **假红也是失败。** 一条总在误报的判据会被关掉，关掉之后就什么都不查了。所以**两头都要演示**。
5. **档位：轻／中／重**，按**最坏后果**定，不按工作量定；三档都**不许省**任何东西——变的只是深度。
6. **一个事实只有一个事实源**；新增读入口必须同时回答"**谁不该看见它**"。
7. **判权链：八条不变量**——拒绝优先、逐层收窄、拒绝应答不泄漏存在性、派生权利不落库……**层数由你的项目自己定**。
8. **实体中立。** 实体"是什么"可以**建议**，绝不能**判定**；目的同一，天性各异。
9. **事故台账 ＋ 可恢复断点**——坏了什么、代价多少、怎么接着干。
10. **多执行者纪律**——写域不重叠、审查者只一个、最终 diff 由一个人过。

## 为什么这不是一堆提示词

- 每条规矩都标了**三态**（已验证／未验证／已知未解）——包括那些**来自推断、而非真实事故**的条目。
- 验证工具随包发布的是**五道核对**，而且**每一道都写明"它不覆盖什么"**。说不清自己盲区的判据，按**未完成**处理。
- 判据是**双向自证**的：既要在已知坏样本上**红**，也要在已知好样本上**绿**。只验一头＝半条判据。
- 收录了**真实的假红标本**（作者本机实测），例如某个 shell 把 UTF-8 按本地遗留代码页解码，把 199 行的文件报成 110 行。

## 它不保证什么（采用前请读）

- **出处**：约 **124 条**引用里只抽核过 **53 条**；章节号一级的锚点**没有**机器校验。
- **技能加载**：只在作者本机观察过。**换机器、换 loader 未实测**。
- **脱敏**：只验到"手写禁用词表命中 0"，**不声明"所有可识别信息都已清除"**。
- **副本**：`resources/` 的九篇是由**固定规则**从**私有源项目**生成的**分发副本**；**生成脚本不随包发布**（它按定义含真名）。⇒ 外部读者**无法复算**副本——"副本可复算"这条保证**只对作者成立**。**请把本仓库当作分发件。**
- **实战面**：规矩提炼自**一个**长期项目，**尚未在第二个项目上验证**。

## 语言

**中文是源，英文是译本**：改动先落中文，英文同轮跟上；**冲突以中文为准**（比"两语平等权威"更硬，见技能包 `TRANSLATION.md`）。

- **已全译**：`SKILL.md`（协议正文）与 `resources/` **九篇**（`00` 目录 ＋ `01`–`08` 正文）——**同目录兄弟对**
  （`<篇名>.md` ＋ `<篇名>.en.md` ＋ `<篇名>.i18n.yaml`），两侧 H1 后都带语言切换行。**不设 locale 目录，不中英混排。**
- **欢迎校对**：译法约定与**术语表**（一个术语只有一个英译，附禁用别名）在技能包 `TRANSLATION.md`；
  改译文后请更新 `*.i18n.yaml` 里两侧的内容哈希（命令见该文件），否则一致性门会红——**这是有意的**。
- **机器能查什么**：完整性／哈希记录／语言切换行／**结构签名**（标题深度、列表条目数、表格行列数、围栏、链接条数）／链接语种／英文侧中文残留。
  **查不出"译文说的是不是同一件事"**——那只能人读；**译文语义尚未经独立对读**，这一点写在技能包 `README.md` 与校验记录里。
